# 명세: 배포 지연 안내 이메일 초안 작성

## 목표
상황 카드를 읽고, 고객사에 보낼 배포 지연 안내 이메일 초안을 쓴다.

## 입력
- `inputs/4_email_scenario.txt` — 가상 상황 카드

## 단계
1. 상황 카드를 읽는다.
2. 정중한 사과 한 줄을 넣는다.
3. 변경된 새 일정을 안내한다.
4. 결과를 `outputs/email-draft.md` 파일로 저장한다.

## 출력 형식
- 인사 → 용건(사과·새 일정) → 맺음말 순서의 짧은 이메일
- 마지막 줄은 `최유라 올림` 서명

## 제약
- 상황 카드에 없는 사실(보상 내용 등)은 지어내지 않는다.

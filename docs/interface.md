# 우리 팀 인터페이스 표 (샘플)

> 앞 회차에 팀이 함께 정한 약속입니다. **칸 이름·받는 것·내놓는 것**은 여기 적힌 대로만 씁니다.
> 여기 없는 이름을 새로 지어 쓰면 다음 칸이 못 받습니다.

## 파이프라인 순서

```
collect(수집) → summarize(요약) → verify(검증) → report(보고)
```

## 칸별 약속

| 칸(한글) | 칸(영문) | 받는 것 | 내놓는 것과 모양 | 못 할 때 |
| --- | --- | --- | --- | --- |
| 수집 | `collect` | 회의록 원문 파일 | 회의 개요(일시·참석자·안건) + 발언 묶음 목록 | 원문이 비어 있으면 "수집 대상 없음"으로 표시 |
| 요약 | `summarize` | 회의 개요 + 발언 묶음 목록 | 핵심 세 줄 + `담당자 / 할 일 / 기한` 표 | 논의만 있고 결정이 없으면 "결정 사항 없음"으로 표시 |
| 검증 | `verify` | 핵심 세 줄 + 할 일 목록(`담당자 / 할 일 / 기한`) | 항목마다 통과 또는 반려와 이유 한 줄이 있는 표 | 확인할 항목이 없으면 "확인 대상 없음"으로 표시 |
| 보고 | `report` | 검증 통과 항목만 모은 표 | 결론 맨 위 + 한 일 / 다음 계획 | 통과 항목이 하나도 없으면 "보고할 내용 없음"으로 표시 |

> **앞 칸이 내놓는 것 = 다음 칸이 받는 것.** 이 줄이 어긋나면 칸이 안 이어집니다.
> 표현을 바꾸고 싶으면 내 칸만 고치지 말고 팀에 먼저 알리세요.

## 자리 규칙

- 내 칸에 필요한 것은 **전부 내 칸 폴더 안에** 둡니다. (`verify/` 칸이면 `verify/` 안)
- 결과 파일 이름은 `result.md`로 통일합니다.
- 남의 칸 폴더는 **읽지도 쓰지도 않습니다.** 필요한 건 받는 것으로 넘겨받습니다.

## 칸별 판단할 것 (앞 회차 메모)

| 칸 | 여기서 판단할 것 |
| --- | --- |
| `collect` | 발언인지 잡담인지 — 안건과 무관하면 버림 |
| `summarize` | 결정인지 논의인지 — 결정만 결정 사항에 올림 |
| `verify` | **담당자가 없으면 반려 · 기한이 없으면 반려 · 원문에 근거 없는 수치는 반려** |
| `report` | 확인된 수치인지 — 미확정 값은 올리지 않음 |

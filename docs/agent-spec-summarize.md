# 개인 에이전트 명세서 - 요약(summarize) 칸

작성자: 최유라

| 명세서 칸 | 내용 |
| --- | --- |
| 이 에이전트가 하는 일 | 정리된 회의 개요와 발언 묶음을 받아 핵심 세 줄과 할 일 목록으로 줄여야 할 때 부릅니다. |
| 입력 | 회의 개요 + 안건별 발언 묶음 목록 |
| 출력 | 핵심 세 줄 + `담당자 / 할 일 / 기한` 표 + 논의만 하고 결정 안 된 것 |
| 쓰는 도구 | Read, Write, Edit, Glob (summarize 폴더 안의 파일을 읽고 쓰는 용도만) |
| 핵심 지시 | 결정인지 논의인지 판단해 결정만 핵심 세 줄에 올림. 담당자·기한이 없으면 `미정`으로 적고 짐작해 채우지 않음. |
| 막힌 점 | 없음 — 담당자가 정해지지 않은 항목을 `미정`으로, "곧 공유"를 원문 표현 그대로 "빠른 시일 내"로 남겼습니다. |

# 개인 에이전트 명세서 - 검증(verify) 칸

작성자: 최유라

| 명세서 칸 | 내용 |
| --- | --- |
| 이 에이전트가 하는 일 | 회의록 요약과 할 일 목록을 받아 항목별로 통과·반려를 가려야 할 때 부릅니다. report 칸으로 넘기기 전 마지막 확인 단계입니다. |
| 입력 | 핵심 세 줄 + 할 일 목록(`담당자 / 할 일 / 기한`) |
| 출력 | 항목마다 통과 또는 반려와 이유 한 줄이 있는 표 |
| 쓰는 도구 | Read, Write, Edit, Glob (verify 폴더 안의 파일을 읽고 쓰는 용도만) |
| 핵심 지시 | 담당자가 없으면 반려 · 기한이 없으면 반려 · 원문에 근거 없는 수치는 반려. 재료에 없는 내용은 지어내지 않음. |
| 막힌 점 | 없음 — 재료의 흠 2건(담당자 미지정 1건, 기한 미표기 1건)을 모두 반려로 잡았고, 빈 재료로 돌렸을 때도 "확인 대상 없음"이 모양 그대로 나왔습니다. |

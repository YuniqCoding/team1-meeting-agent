# 개인 에이전트 명세서 - 수집(collect) 칸

작성자: 최유라

| 명세서 칸 | 내용 |
| --- | --- |
| 이 에이전트가 하는 일 | 회의록 원문에서 회의 개요와 안건별 발언 묶음을 정리해 뽑아내야 할 때 부릅니다. 파이프라인의 첫 칸입니다. |
| 입력 | 회의록 원문 파일 |
| 출력 | 회의 개요(일시·장소·참석자·안건) 표 + 안건별 발언 묶음 목록 + 버린 발언 표 |
| 쓰는 도구 | Read, Write, Edit, Glob (collect 폴더 안의 파일을 읽고 쓰는 용도만) |
| 핵심 지시 | 발언인지 잡담인지 판단해 안건과 무관하면 버림. 단, 버린 것은 이유와 함께 표로 남김. 애매하면 버리지 않음. |
| 막힌 점 | 없음 — 잡담 3건(샌드위치집 2건, 회식 장소 1건)을 모두 버린 발언 표로 빼냈습니다. |

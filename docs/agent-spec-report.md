# 개인 에이전트 명세서 - 보고(report) 칸

작성자: 최유라

| 명세서 칸 | 내용 |
| --- | --- |
| 이 에이전트가 하는 일 | 검증을 통과한 항목만 모아 결론이 맨 위에 오는 보고서로 정리해야 할 때 부릅니다. 파이프라인의 마지막 칸입니다. |
| 입력 | 검증 통과 항목만 모은 표 |
| 출력 | 결론 맨 위 + 한 일 / 다음 계획 + 확인 필요 + 용어 풀이 부록 |
| 쓰는 도구 | Read, Write, Edit, Glob (report 폴더 안의 파일을 읽고 쓰는 용도만) |
| 핵심 지시 | 확인된 수치만 올림. 미확정 값은 `수치 미확정`으로 적고 짐작한 숫자를 넣지 않음. 반려 항목은 본문이 아니라 "확인 필요"에만 남김. |
| 막힌 점 | 없음 — 반려 2건이 본문에 섞이지 않았고, 집계 전인 참여율은 `수치 미확정`으로 남았습니다. |
